# 롱폼 편집 프롬프트

아무 폴더에서나 Claude Code를 열고 아래를 붙여 넣는다. `{ }` 부분만 바꾼다.
`longform-edit` 스킬이 자동으로 불린다. 안 불리면 첫 줄에 `/longform-edit`를 붙인다.
스킬은 작업 전에 질문 7개(기획안·카메라 수·레퍼런스·길이·에셋·마무리 툴·화질)를 먼저 묻는다 — 아래 [입력]에 적은 건 다시 묻지 않는다.

---

## 1차 편집 지시 (복붙용)

```
/longform-edit
롱폼 편집해줘. 제목은 「{영상 제목}」.

[입력]
- 촬영본 영상: {경로 — 예: ~/Desktop/촬영/A캠.mp4, B캠.mp4}
- 촬영본 사운드: {경로 — 예: ~/Desktop/촬영/ZOOM0001.wav / 없으면 "카메라 오디오 사용"}
- 예시 영상: {경로 또는 유튜브 링크}
- 편집 에셋: {폴더 경로 — 폰트, 컬러 코드, 자막 디자인, 채널 로고, BGM, 효과음}
- 목표 길이: {예: 15분 내외 / 예시와 비슷하게}

[진행 순서 — 각 단계 끝나면 짧게 보고]
0. SD카드가 꽂혀 있으면 프로젝트 폴더(촬영본/편집본/편집자료/에셋)를 만들고 촬영본으로 백업·검증해.
1. 촬영본을 확인하고 싱크를 먼저 맞춰.
2. 사운드를 전사하고 기획안과 대조해 검수한 뒤, 예시 영상을 분석해서 그 구성대로 구성안을 작성해. → 내가 확인할 때까지 멈춰.
3. 구성안 승인 후, 예시 영상 분석 내용과 채널 에셋을 정리해서 보여주고 확인받아. → 확인받을 때까지 멈춰.
4. 예시 영상과 편집 호흡(평균 컷 길이, 분당 컷 수)이 비슷하도록 구성안 지시대로 컷편집해.
   여러 캠이면 컷을 섞고 호흡을 맞추고, 음·어·반복은 없애.
5. 색보정과 컷 위치(구도)를 조정해서 모든 화면이 균일하게 보이게 하고,
   목소리 크기는 모든 장면에서 일정하되 소음은 들리지 않게 사운드를 보정해.
6. 자막 위치·색·디자인, 효과음, 로고를 처음부터 끝까지 동일하게 넣고(에셋 없으면 프리텐다드·흰 글자·검정 외곽선·살짝 그림자),
   예시 영상을 참고해 강조 자막, 줌인·줌아웃, 효과음, 배경음악을 넣어 마무리해.
7. 편집자료·중간저장·렌더자료는 전부 `편집자료` 폴더에, 완성본은
   「{영상 제목}_1차 편집본.mp4」(다른 조건 없으면 540p)로 `편집본` 폴더에 저장해. 2차부터는 1080p.
8. 1차본이 나오면 편집본 폴더를 Finder로 열어줘.
9. 피드백기록.md의 이전 피드백을 참고해서 이번에 나올 피드백을 예측해줘.

[규칙]
- 원본 파일은 수정하거나 옮기지 말고 복사해서 써.
- 승인 지점(2, 3)에서는 반드시 멈추고 내 답을 기다려.
- 끝나기 전에 예시 영상 분석 수치와 1차본 QC 수치를 표로 비교해줘.
```

## 피드백 반영 지시 (2차·3차, 복붙용)

```
{N}차 피드백이야. 반영해서 「{영상 제목}_{N+1}차 편집본」 뽑아줘.

{피드백 — 타임코드가 있으면 같이. 예:
- 03:12 컷 너무 빨라. 리액션 1초 더 살려줘
- 자막 노란 강조 너무 많아. 핵심 단어만
- 07:40~08:10 BGM이 목소리를 덮어}

[반영 후 꼭 할 것]
- 피드백을 번호 붙인 체크리스트로 쪼개고, 항목마다 "반영 위치(타임코드) / 확인 방법 / 결과"를 채워서 빠진 게 없는지 스스로 점검해. 확인은 프레임 추출·자막 비교·QC 수치 같은 증거로.
- 이전 차수에서 맞았던 부분이 깨지지 않았는지도 확인해.
- 피드백을 피드백기록.md에 누적해.
- 다 끝나면 예시 영상 분석 내용과 다르지 않은지 최종 대조표를 주고, 편집본 폴더를 Finder로 열어줘.
```

## 짧은 버전 (스킬이 다 알고 있을 때)

```
/longform-edit
「{제목}」 롱폼 편집. 촬영본 {경로}, 사운드 {경로}, 예시 {경로}, 에셋 {경로}.
```

```
2차 피드백: {내용}
```

## 결과물 위치

```
<프로젝트 폴더>/{제목}/          (위치는 ~/.longform-edit/config.json 의 projects_root)
  촬영본/     A캠/ B캠/ 사운드/ … (SD카드 백업본, 읽기만)
  편집본/     {제목}_1차 편집본.mp4(540p), _2차(1080p), _3차
  편집자료/   기획안·레퍼런스·싱크·전사·구성안·에셋확인·편집결정·자막·QC·중간저장·렌더캐시·XML·SRT
  에셋/       폰트·로고·BGM·효과음·그래픽
<프로젝트 폴더>/피드백기록.md   ← 프로젝트를 넘어 누적되는 피드백 장부
```

## 알아둘 것

- **예시 영상이 유튜브 링크면** 다운로드 허락을 따로 묻는다(파일명·출처 확인 후 진행).
- **폰트는 파일로** 에셋 폴더에 넣어야 자막에 정확히 들어간다(설치만 돼 있고 파일이 없으면 다른 폰트로 대체될 수 있음).
- 프리미어에서 손보고 싶으면 `편집자료/{제목}_타임라인.xml`을 가져오면 된다. 이 XML에는 컷 타임라인(영상+목소리)만 들어 있고, 자막·BGM·색보정은 MP4에만 입혀진다.
- 2·3차 수정 때는 바뀐 컷만 다시 렌더된다(렌더캐시).
